# 🎧 Анти-ИИ Аудиометр

**Бесплатный офлайн-тест слуха | Социальный проект | Anti-AI Shield**

---

## 📱 О проекте

Анти-ИИ Аудиометр — это полностью автономное веб-приложение для проверки слуха.  
Проект не требует интернета после загрузки и не собирает персональные данные.

### 🎯 Что вы получите:

- Проверка слуха на 7 частотах: **125, 250, 500, 1000, 2000, 4000, 8000 Гц**
- Профессиональные синусоидальные тоны через Web Audio API
- Голосовое сопровождение и подсказки
- Подробную расшифровку результатов с рекомендациями
- Полную анонимность — никаких серверов и сбора данных
- Красивый стеклянный интерфейс (Glassmorphism)
- Защиту от угадывания — строгое окно реакции 1 секунда

---

## 🛡️ Почему «Анти-ИИ»?

Приложение невозможно сдать «на автомате» — алгоритм требует реальной реакции на случайный звуковой сигнал.  
С выключенным звуком пройти тест математически невозможно (вероятность < 0.001%).
